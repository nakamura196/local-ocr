Windows 版は、Microsoft ストアが自動で新しい版に替えます。
Mac 版は自動では替わりません。新しい版は [Releases](https://github.com/nakamura196/local-ocr/releases/latest) からダウンロードし、Applications フォルダの古いものと入れ替えてください。
読む道具（モデル）は入れ替えても消えないので、取得し直す必要はありません。
{: .point }

日付は日本時間です。

### 0.1.8（2026年10月4日）

- Yigdzin-1（チベット語）で、写真に物差しが写っていると、ページ全体が「文字が見つかりませんでした」になることがありました。読めなかった行だけを飛ばし、残りの行は結果に出すようにしました。
- 読み取りに失敗したときに、「文字が見つかりませんでした」と表示しないようにしました。失敗したことがそのまま伝わります。
- 行の読み直しで、短い記号（༄༅། །など）だけが残って本文が消えることがあったのを直しました。

### 0.1.7（2026年10月2日）

- Yigdzin-1（チベット語）で、写本の行を読み終えても止まらず、同じ語を繰り返し続ける問題を直しました。1 ページに数分かかり、結果が繰り返しで埋まっていました。各行の読みだけが残り、1 ページ 20 秒〜1 分ほどで読み終わります。
- 物差しや紙の端を行として読んでしまったときは、その行を結果に含めないようにしました。

### 0.1.6（2026年9月28日）

- 画像の一部を囲んで、その範囲だけを読めるようになりました。
- 読み方を、読む道具ごとに設定画面で選べるようになりました。
  - PaddleOCR-VL: 「文字だけ」（これまでどおり）と「行の位置も付ける」
  - NDL の 2 つ: 「版面から行を探して読む」（これまでどおり）と「1 行として読む」
- PaddleOCR-VL の「行の位置も付ける」で、行を縦書きの読む順に並べ直すようにしました。割注は右の列、左の列の順に並びます。
- 行の読み落としや、同じ字の繰り返しが起きたときは、画面でお知らせするようにしました。

### 0.1.5（2026年9月26日）

- TEI/IIIF エディタの「ページ OCR」で、PaddleOCR-VL を使えるようになりました。行ごとに位置（枠）も付きます。
- 定規が写った画像で、PaddleOCR-VL の読み取りが崩れる問題を直しました。
- エディタの新しい URL（tei-editor.ldas.jp）から、設定を変えずにつながるようにしました。

### 0.1.4（2026年9月25日）

- スクロールバーを濃く、太くして、見つけやすくしました。
- 「くらべる」画面で、読む道具を選ぶ欄が画面からはみ出さないようにしました。
- 大きな画像を表示するときに縮小してから送るようにして、動作を軽くしました。

### 0.1.3（2026年9月24日）

- チベット語を読む道具「Yigdzin-1」を追加しました。

### 0.1.2（2026年9月23日）

- Mac で、ファイルを開く画面と保存する画面が日本語で出るようになりました。
- メニューに、読む道具の正式な名前を出すようにしました。
- ダウンロードの大きさの単位をそろえました。

### 0.1.1（2026年9月23日）

- 日本語の Mac で、初めて起動したときに英語の画面が出る問題を直しました。
- 読む道具（モデル）を置くフォルダを、環境変数 `LOCAL_OCR_DATA_DIR` で変えられるようにしました（詳しい方向け）。

### 0.1.0（2026年9月22日）

最初の版です。Mac 版を公開し、続けて Windows 版を Microsoft ストアで公開しました。

- 画像を読み、結果を確かめて、テキストか TEI/XML で保存できます。
- 読む道具: NDLOCR-Lite（現代の活字）、NDL古典籍OCR-Lite（古典籍・くずし字）、PaddleOCR-VL（漢籍・多言語）、Apple Vision（Mac のみ）。
- 「くらべる」画面で、2 つの道具の結果を並べて見られます。
